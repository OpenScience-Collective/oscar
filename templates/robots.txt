# OSCAR starter: robots.txt
#
# Tier: Core. Every token below is documented by its own vendor, and the major
# crawlers state that they honor robots.txt. See docs/evidence.md for citations.
#
# Explicitly welcome the AI agents you want to use your content.
# Three roles matter, and you may want to treat them differently:
#   - "training" crawlers, which may use your content to train models
#       GPTBot, ClaudeBot, CCBot, meta-externalagent
#   - "search index" crawlers, which build an index answers are cited from
#       OAI-SearchBot, Claude-SearchBot, PerplexityBot
#   - "user fetchers", which retrieve one page to answer a live question
#       ChatGPT-User, Claude-User
# Google-Extended and Applebot-Extended are NOT crawlers. They are tokens
# evaluated against pages Googlebot and Applebot already fetched, so they let
# you control model training and grounding without leaving Search.
#
# For most open-science content you can Allow all of them.
# For licensed or restricted research DATA, consider allowing the search and
# user fetchers while disallowing the training crawlers (set "Disallow: /").
#
# Note: naming a token states your policy; it does not enforce it. Perplexity's
# own documentation says Perplexity-User generally ignores robots.txt on live
# fetches, and Cloudflare documented undeclared user agents fetching pages that
# disallow PerplexityBot.
#
# Token references:
#   Anthropic: https://support.claude.com/en/articles/8896518  (verify: https://claude.com/crawling/bots.json)
#   OpenAI:    https://platform.openai.com/docs/bots

# Everyone, including ordinary search engines.
User-agent: *
Allow: /

# The AI-adjacent tokens, named explicitly.
# Stacked "User-agent" lines sharing ONE rule are valid robots.txt syntax: every
# agent listed until the first rule line takes that rule. This block is
# redundant under the wildcard above, and it is still worth writing, because it
# states your policy in the form several vendors' own tooling checks for, and it
# is the file a person reads to learn what you allow.
User-agent: GPTBot
User-agent: OAI-SearchBot
User-agent: ChatGPT-User
User-agent: ClaudeBot
User-agent: Claude-SearchBot
User-agent: Claude-User
User-agent: PerplexityBot
User-agent: Google-Extended
User-agent: Applebot
User-agent: Applebot-Extended
User-agent: meta-externalagent
User-agent: CCBot
Allow: /
